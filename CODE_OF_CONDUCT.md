# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, and remember that the people
on the other side of an issue thread are human.

Report abusive behaviour to harry@hvass.dev (or open a private issue if
the conduct involves the maintainer themselves).
